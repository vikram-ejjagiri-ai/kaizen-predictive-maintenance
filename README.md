# Kaizen Predictive Maintenance

Predicting the Remaining Useful Life (RUL) of machines from sensor data,
using the NASA C-MAPSS turbofan engine dataset.

## Dataset

Download CMAPSSData.zip from https://data.nasa.gov/docs/legacy/CMAPSSData.zip
and unzip it into data/raw/cmapss/. The data is not included in this repository.
